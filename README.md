Datheon Python Internship

Overview

This repository contains beginner-friendly Python projects developed for the Datheon Python Programming Internship.

Project 1: Hangman Game

A console-based word guessing game featuring:

- Random word selection
- Six incorrect attempts
- ASCII hangman stages
- Duplicate-guess protection
- Win and loss messages

File: "hangman.py"

Project 2: Interactive Python Chatbot

A rule-based terminal assistant featuring:

- Greeting recognition
- FAQ responses
- Regular expression matching
- Unknown-query handling
- Exit commands

File: "chatbot.py"

Requirements

- Python 3
- A Python interpreter or online Python compiler

How to Run

Download the project files and run either command in a Python terminal:

python hangman.py
python chatbot.py

Learning Outcomes

- Python variables and data types
- Conditional statements and loops
- Functions and collections
- String manipulation
- Regular expressions
- Input validation

Internship Submission

These projects are prepared for submission toward the Datheon Python Programming Internship. They must be tested and reviewed before final submission.
